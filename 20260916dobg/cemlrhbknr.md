# 产后突遭肺栓塞命悬一线！湖北援疆妇产专家临危“救命”

> 更新时间：2026-09-16 (UTC+8)

在产下婴儿后下床活动时，突发急性肺栓塞，命悬一线，41岁的沙女士（化名）在“鬼门关”走了一遭......11月22日，湖北援疆医疗队与新疆温泉县人民医院多学科专家联动紧急抢救，沙女士转危为安，已康复出院。

今年41岁的沙女士，体重102公斤。11月8日，怀三胎足月的沙女士到该院妇产科待产，通过剖宫产术顺利产下一女婴，身长50厘米，体重3.3千克，全家沉浸在母女平安的喜悦中。

11月9日早上，术后9小时的沙女士下床活动时，突然晕倒在地，家人以为是手术后禁食导致的低血糖，继而出现口吐白沫，嘴唇青紫，呼吸困难，很快就陷入了昏迷。护理人员迅速到病房中，为其吸氧、测血糖、补液、监护，并呼叫妇产科援疆医生宋华梅。

宜昌市中心人民医院西陵院区产科副主任医师宋华梅，是湖北援疆医生之一。宋华梅介绍，当时沙女士已丧失意识，监护仪显示血氧饱和度60%（正常值100%），血压89/55mmHg。“我第一时间判断她很有可能产生了急性肺栓塞。产后肺栓塞的发生率很低，但致死率极高，如果治疗不及时，几乎无生还可能。”宋华梅说。

抢救过程中，宋华梅临危不乱，第一时间指挥麻醉医师行气管插管，呼吸机辅助呼吸。随即，该院立即启动多学科会诊，重症医学科援疆专家胡波医师急救团队与医学影像科援疆专家王思洋医师也参与到抢救中。经2小时紧急抢救，沙女士的生命体征终于平稳，转危为安。

“肺栓塞是孕产妇的隐形杀手，死亡率极高，发生前几乎无法预测。孕产妇特别是产后，血液呈高凝状态，加上活动少，易致血液循环不通畅，很容易形成下肢血栓，血栓一旦脱落，就会随血液流动到达肺，把肺动脉塞住，形成肺栓塞。从发病到死亡只需短短几分钟时间，根本来不及抢救，可以说是瞬间夺命。”宋华梅介绍，孕产妇是发生肺栓塞的高危人群，特别是肥胖、高龄，产后肺栓塞发生的几率比产前高15倍。

此次沙女士的成功救治，与妇产科医护团队紧急措施、多学科团队的紧密合作分不开，标志着温泉县人民医院在急危重症孕产妇的救治能力迈上一个新的台阶，也是湖北援疆医疗队切实发挥医疗援疆作用的重要体现。
沙女士出院时特地为宋华梅及医护团队送上锦旗：“非常感谢宋主任和其他援疆医生对我的精心治疗，你们是我的救命恩人！”
/ 宜昌市中心人民医院 /
